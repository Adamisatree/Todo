# Linea Tasks

**把今天，过得漂亮。** 一个离线优先、简约线条风格的桌面任务管理器，适合日常待办、课程作业和项目计划。无需注册账号，没有云端依赖。

## 功能

- **任务规划**：今天、收件箱、即将到来、所有任务、重要任务、已完成、归档；自定义彩色项目。
- **任务详情**：备注、截止日期与时间、优先级、项目、标签、子任务、预估用时、星标、进行中状态。
- **重复任务**：每天、工作日、每周、每月；完成有截止日期的重复任务后，自动生成下一次待办，不会一次性生成一堆过期任务。
- **提醒**：到点或提前 5 分钟 / 15 分钟 / 30 分钟 / 1 小时 / 1 天的系统通知（**应用运行期间**生效）。
- **全局搜索**：查找标题、备注、标签、子任务和项目名，也能搜到已完成任务；按优先级筛选、智能/日期/优先级/创建时间/名称排序。
- **批量管理**：全选当前列表，批量完成、恢复、归档、取消归档、调整优先级、移动项目、删除；操作后可短暂撤销。
- **专注模式与统计**：可调时长的专注/休息计时器，最近七天完成趋势和项目进度。
- **数据安全**：桌面端数据保存在系统用户数据目录的 `linea-data.json`，写入时使用临时文件，并保留上一次数据的 `.bak` 备份；支持 JSON 导入和导出。浏览器预览则使用浏览器本地存储。
- **深色 / 浅色主题**、快捷键、响应式布局。

首次打开会显示一些可以随时修改、完成或删除的示例任务和项目。

## 获取桌面应用

在仓库的 **Actions → Desktop builds** 中下载构建产物（推送到本会话分支或手动运行工作流时生成）：

| 系统 | 下载文件 | 说明 |
|---|---|---|
| Windows x64 | `Linea-Tasks-*-win-x64-setup.exe` | 双击运行安装程序，可选安装位置 |
| macOS Intel | `Linea-Tasks-*-mac-x64.zip` 或 `.dmg` | ZIP 解压后得到 `.app`，DMG 中可拖入“应用程序” |
| macOS Apple Silicon | `Linea-Tasks-*-mac-arm64.zip` 或 `.dmg` | 与上面相同，适用于 M 系列芯片 |

macOS 构建使用 ad-hoc 代码签名，但**没有 Apple Developer ID 签名或公证**；Windows 也未使用代码签名证书。若 macOS 显示“文件已损坏”或 Windows 出现 SmartScreen，请先阅读 **[常见问题与故障排查](docs/FAQ.md)**，核实来源、架构与构建产物内的 `SHA256SUMS.txt` 后再处理。**运行应用不需要联网**。

> 此仓库的 CI 需要 GitHub Actions 正常运行；若未看到构建产物，可在对应系统上自行构建。macOS `.app` 必须在 macOS 上打包，Linux 开发环境不能直接生成最终 `.app`。

> **macOS“文件已损坏”？** 不要直接关闭系统安全防护。按 [FAQ 第 1 节](docs/FAQ.md#1-macos-弹出linea-tasksapp已损坏无法打开你应该将它移到废纸篓) 的顺序排查；该文档也涵盖签名校验、Windows 安装和数据恢复。

## 本地开发与打包

需要 Node.js 22+、npm。

```bash
npm ci
npm run dev           # 浏览器预览，http://localhost:5173
npm run desktop:dev   # Electron 桌面调试
npm test              # 逻辑测试
npm run build         # 类型检查 + 构建静态前端
npm run package:win   # Windows 上打包 EXE
npm run package:mac   # macOS 上打包 Intel + Apple Silicon 的 DMG/ZIP
```

打包输出在 `release/`（已忽略，不会进入 Git）。应用资源全部随包提供，运行时不依赖 Vite 服务器或外部 API。

## 常用快捷键

| 快捷键 | 操作 |
|---|---|
| `Ctrl / ⌘ + K` 或 `/` | 搜索 |
| `N` | 快速添加任务 |
| `Enter` | 保存快速添加的任务 / 子任务 / 标签 |
| `Esc` | 关闭详情或退出选择 |

## 数据说明

本项目没有账户系统或跨设备自动同步。若要换设备，请先在 **设置 → 数据管理 → 导出** 保存 JSON，再在另一台设备上 **导入**。导入会替换当前所有任务和项目，操作前建议先导出备份。任务提醒仅在应用开启时触发；专注计时器不在退出应用后继续运行。
