# Linea Tasks

**把今天，过得漂亮。** Linea 是一款面向日常待办、课程作业与个人计划的离线桌面任务管理器：用任务、项目、子任务和重复规则安排事情，用预估时长与专注计时帮助自己执行。界面提供深色 / 浅色的简约线条风格。**无需注册、无需网络、无需启动网页服务器即可使用安装好的桌面应用。**

> 当前版本：**v1.1.1** · Windows x64 / macOS Intel / macOS Apple Silicon · [常见问题与故障排查](docs/FAQ.md)

## 快速上手

1. **记录一件事：**在“今天”页面输入任务标题；标题框下面可直接填写预估的**小时、分钟**，也可选截止日期和项目。按 `Enter` 或右侧箭头保存。
2. **补充细节：**点击任务行，在右侧详情里填写备注、截止时间、优先级、标签、子任务、提醒和重复规则。
3. **安排优先顺序：**在列表右上角按优先级、截止日期、用时等排序；需要自己排次序时切到“手动排序”，拖动任务左侧把手，或点上下箭头。
4. **执行与回顾：**勾选完成；打开“专注模式”开始计时；在“效率统计”看最近 7 天完成情况。跨设备迁移前到“设置 → 数据管理”导出 JSON 备份。

**每天背单词 3 次的例子：**新建“背单词” → 在详情中设置截止日期为今天、重复为“每天”、每天完成次数为 `3`、每次预估 `0 小时 20 分钟`。第一次和第二次完成后任务仍排在今天；第三次完成后才排到明天。今天不做可点“跳过”；做完还想继续可点“今天加练”（额外的一次不会推迟明天原计划）。

## 功能详解

### 1. 任务、项目与智能视图

| 位置 | 显示什么 / 用来做什么 |
| --- | --- |
| **今天** | 截止日期是今天的未完成任务，以及此前已逾期的未完成任务；逾期任务单独成组。首页卡片显示待处理数、今日待做数、今日完成数和今日任务总时长。 |
| **收件箱** | 尚未指定所属项目的未完成任务。适合快速记下暂时没整理的想法；并不要求任务没有截止日期。 |
| **即将到来** | 截止日期在明天及以后的未完成任务，分成“明天”和“接下来”。 |
| **所有任务** | 所有未归档、未完成任务；首页的“待办总时长”统计这里的待办。 |
| **重要任务** | 加星标且未完成的任务。任务列表与详情均可切换星标。 |
| **已完成** | 已完成与已跳过的历史任务；跳过的记录有“已跳过”标记，不计入完成统计。 |
| **归档** | 收起而不删除的任务，可在详情或批量工具中取消归档。普通待办和全局搜索不包含归档任务。 |
| **我的项目** | 自定义项目名称与标记颜色，按项目查看待办；可重命名。删除项目时，项目内任务转入收件箱，不会随项目删除。 |
| **专注模式 / 效率统计** | 分别用于专注计时和查看完成趋势、项目进度。 |

每个任务可设为**待处理、进行中、已完成**。点击任务行右侧打开详情；点击任务左侧圆圈直接完成或恢复。第一次打开会带有可自由修改、完成或删除的**示例任务与项目**。

### 2. 新增任务与任务详情

- **快速新增：**输入标题并保存；可以在输入框下设置预估小时与分钟（均为 `0` 表示未估时），同时选截止日期、所属项目。“今天”中新建且未另外选日期时默认到期日是今天；其他视图的新任务可留待安排。
- **基本信息：**任务标题、自由文本备注、截止**日期**与**具体时间**、优先级（无 / 低 / 中 / 高）、所属项目、预估用时（最长 24 小时）。具体时间是用于到点提醒的截止时间，不等同于预估耗时。
- **拆分工作：**添加、完成、删除子任务；为任务增加或删除标签。列表会显示项目、截止时间、预估用时和子任务进度等信息。
- **状态与整理：**可标星、切换进行中、完成、归档或删除。任务与项目删除需要确认；归档不同于删除，归档任务仍保留在本机。
- **修改预估：**新建时填的预估用时也可在任务详情的“时 / 分”输入框调整，首页总时长随之更新。未设置预估的任务会在卡片上以“未估时项数”提示。

### 3. 重复任务、每天多次与跳过

在详情中先设置**截止日期**，然后选择“不重复 / 每天 / 工作日 / 每周 / 每月”。如果没有截止日期，完成任务不会自动创建下一次。默认每天只需完成 **1 次**；“每天”和“工作日”可将“每天完成次数”设为 `1–99`：

- **未达到当天目标：**完成一次，记录一次完成历史，自动创建仍在**今天**的下一次待办；子任务进度会在下一次重置。
- **达到当天目标：**下一次待办排到下一个日期；“工作日”会跳过周末。每周和每月按照相应周期排下一次，错过的多个周期不会一次生成一长串过期任务。
- **跳过本次：**任务行或详情点击“跳过”，该次记录为“已跳过”（不计入完成），下一次按**设备的本地系统日期**安排，日常任务进入下一天。不会因为原任务的远期日期而连续跳到一年以后。
- **今天加练：**为“每天 / 工作日”任务额外创建一条**仅今天的一次性任务**；原定的重复计划不会被推迟。

日期取自电脑的**本地系统时间与时区**，应用不联网校时；请确保系统时间正确。打开的应用会定期刷新日期，切回窗口时也会更新。如果旧版本已经把某个重复任务排到了很远的未来，可以先导出备份，再在该任务详情把截止日期手动改回今天。

### 4. 预估时长与首页汇总

每条任务可单独估时。首页“**今日任务总时长**”汇总今天与已逾期的未完成任务；切到“所有任务”看“**待办总时长**”。每天多次的任务会按**今天剩余次数 × 每次预估时长**计算，例如“单词每天 3 次、每次 20 分钟”，还没做时计入 60 分钟，做完一次后计入 40 分钟。未估时的任务不被当作 0 分钟已完成计划：卡片会同时提示还有多少项没估时。

> 预估时长是规划值，不是自动记录的实际耗时；专注计时不会自动改写任务的预估值或把任务标为完成。

### 5. 搜索、筛选与排序

- 顶部搜索框跨未归档的待办和已完成任务搜索：匹配**标题、备注、标签、子任务标题、项目名**。归档任务需进入“归档”查看。
- 列表可筛选**全部 / 高 / 中 / 低 / 无优先级**。搜索词与优先级筛选可同时使用；如果结果为空，先检查是否启用了筛选。
- 排序选择有：**智能排序**（进行中优先、再按到期日和优先级）、**截止日期**、**优先级**、**最近创建**、**任务名称**、**预估用时短到长**、**预估用时长到短**和**手动排序**。
- 选择“手动排序”后，可拖动任务左侧把手，或用每行的上下箭头调整；当前可见列表的调整会保存到本机，切到其他排序方式不会清除手动顺序。排序方式本身也会保存。

### 6. 批量管理与撤销

点击列表上方的“**批量管理**”，选择若干任务或“全选当前列表”（仅选当前搜索 / 筛选结果），可以批量：**完成、恢复待办、归档 / 取消归档、设优先级、移动到项目 / 收件箱、删除**。单任务完成、跳过、归档与部分批量操作完成后会出现短暂的“撤销”提示。

> 删除不是移到垃圾箱。删除确认后只能在撤销提示仍显示时撤回一次；过后要依赖自己先前导出的备份。重要任务建议用“归档”而不是删除。

### 7. 到期提醒

任务需同时设置**截止日期、具体时间和提醒提前量**；提醒可选：到点、提前 5 / 15 / 30 分钟、提前 1 小时或提前 1 天。还需在“设置”中启用提醒，并允许系统的通知权限。

**只有应用运行时才会检查并发送桌面通知。**退出应用、电脑休眠或错过提醒窗口后，不保证补发；这不是系统级常驻后台闹钟。浏览器预览的通知另受浏览器权限影响。

### 8. 专注模式、统计与个性化

- **专注模式：**默认 25 分钟专注、5 分钟休息；可在设置中修改时长。支持开始、暂停、重置、切换专注 / 休息，以及选择当前要专注的任务。计时结束时（应用仍运行且允许通知）可提示。退出应用后计时不会继续或恢复；选定专注任务也不会自动完成该任务。
- **效率统计：**累计完成数、完成率、项目数；最近 7 天逐日完成数量图，以及各项目已完成 / 总任务的进度。跳过记录不计入完成数量。
- **外观：**深色与浅色主题切换；桌面端窗口有适配较窄布局的界面。设置还提供提醒开关、专注时长、数据导入导出。

### 9. 常用快捷键

| 快捷键 | 用途 |
| --- | --- |
| `Ctrl + K`（Windows）/ `⌘ + K`（macOS） | 聚焦搜索框 |
| `/` | 在未输入文字时聚焦搜索框 |
| `N` | 在未输入文字时聚焦快速新增任务 |
| `Enter` | 在对应输入框内保存快速任务、子任务或标签 |
| `Esc` | 关闭详情 / 设置，或退出批量选择 |

## 离线数据、备份与隐私

- **桌面应用：**数据只保存在本机 Electron 用户数据目录（通常 macOS：`~/Library/Application Support/Linea Tasks/`，Windows：`%APPDATA%\Linea Tasks\`）中的 `linea-data.json`。保存使用临时文件，并保留上一次文件的 `.bak` 副本。
- **浏览器预览：**使用当前浏览器的 localStorage，与桌面应用**不是同一份数据**；清理浏览器站点数据可能清除预览任务。预览不是推荐的长期备份位置。
- **导出：**“设置 → 数据管理 → 导出”生成 JSON 文件，适合定期备份或换电脑。**导入** JSON 会替换当前设备的全部任务、项目和设置，导入前请先导出当前数据。
- **升级与卸载：**正常更换应用版本不会主动删除用户数据；卸载程序和删除用户数据是不同的事。若要手动处理损坏的数据文件，先退出应用并复制原文件及 `.bak`，再参阅 [FAQ](docs/FAQ.md)。
- **明确的限制：**没有账号、自动云同步、多人协作或跨设备实时同步；不上传任务数据，也不要求互联网才能使用已安装的应用。下载新版本和手动备份迁移另需自行处理。

## 安装异常与校验

发布页在三个安装包旁列有各自的 **SHA-256**。如果下载不完整、选错架构，或系统提示文件损坏，先核对文件名、芯片类型和摘要；不要直接关闭 Gatekeeper、SIP 或杀毒软件。macOS 仍可能因为**未公证**而阻止第一次运行：请按 **[《常见问题与故障排查》](docs/FAQ.md)** 的顺序处理，文档也包括 Windows SmartScreen、数据恢复、日期不对和提醒未触发等问题。

## 开发、测试与本地打包

需要 **Node.js 22+** 和 npm。本仓库使用 Electron + React + TypeScript + Vite；运行时不依赖在线 API。

```bash
npm ci                  # 安装依赖
npm run dev             # 浏览器预览： http://localhost:5173
npm run desktop:dev     # Electron 桌面调试
npm test                # 运行逻辑与交互测试
npm run build           # 类型检查 + 构建静态前端
npm run package:win     # 在 Windows 上构建 x64 EXE
npm run package:mac     # 在 macOS 上构建 Intel 与 Apple Silicon 的两个 DMG
```

打包输出位于已被 Git 忽略的 `release/`。`.github/workflows/build.yml` 在 Windows 和 macOS 运行测试、构建和 macOS 签名校验，随后将**三个独立安装包**发布到 GitHub Release；Actions 中的 ZIP 仅用于 CI 任务间传递构建产物，不是给最终用户下载的入口。macOS 构建仍未经 Apple 公证。

代码入口：`src/App.tsx`（界面交互）、`src/taskUtils.ts`（日期 / 重复 / 筛选 / 排序）、`src/storage.ts`（本地存储与导入导出）、`electron/`（桌面进程与文件持久化）；测试见 `src/*.test.ts*`。
